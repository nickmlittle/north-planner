Desktop · Add item and Edit item are one editor

Before: Add opens a batch table that starts with Category, then owner → account → pot bubbles, with Name further down (10 clicks + 3 fields with the first amount change). Edit is a different single-item form. After: one editor for both, in the order you think: name, amount, where it goes (recent destinations as one-tap chips), then category and funding pre-filled from the last item. ⌘↵ saves and starts another.
