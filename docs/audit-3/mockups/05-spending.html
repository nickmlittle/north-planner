Spending: the card, from bring in to settle up

Job 3. Spending keeps only the card's own work. Three tabs (To sort, Transactions, Statements) sit under one header, with one primary action: Bring in. Setting money aside becomes the last step of sorting rather than a banner on every sub-page. A statement's page leads with Settle up, built from the same step rows as payday. Rules, the right-hand rail and "This month" move out: rules to Settings, pots to Month. Fixes F03, F05, F13, F19, F20. Briefs: PR 13, PR 14, PR 15.

  • The header line carries the card's status (statement so far, closing date, Amex pot), so the summary card, the banner and the side panel go.
  • No Place buttons: ↵ places the focused row, and clicking a row focuses it. The suggestion is a chip inside the field, so it can't be cut off.
