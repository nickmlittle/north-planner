# Mobile Transfers matrix preview

On a mobile-sized Transfers page, select **Preview matrix**. The preview uses the selected month and current budget. Select **Return to account view** to restore the existing account overview and its detail links. The preview choice lives only in the mounted page's memory: it defaults off on a fresh page load, does not change the URL, and is not saved to the budget. Existing account deep links continue to open the account detail; desktop keeps its current view. If the mapping cannot be built, the account overview remains available with a notice.

The matrix shows receiving-account totals followed by their direct and pot allocations. Account labels use owner and account name; provider appears only when needed to distinguish two visible accounts. Select an account to hide or show its allocations. Select an allocation to show or hide its item rows, including each item's category and rounded contributor amounts. A single item going directly to an account stays on one compact account row until expanded. Account, allocation and item rows are nested breakdowns, so they must not be added together.

Following the Phase 3 spreadsheet comparison, displayed table amounts are independently rounded to whole pounds. The table warns that rounded values may not add up. The underlying calculation remains exact pence, and incomplete allocations show planned and unallocated amounts in pounds and pence. Exact-pence display and copy actions are deferred to a later interaction slice. When columns overflow, a cue appears and the table can scroll horizontally with a sticky first column or arrow keys.

This remains an opt-in matrix of planned contributions. It does not record payments. The existing Plan and Transfers navigation, editing workflow, and account detail remain available. Phase 3 and Phase 4a were approved; Phase 4b's Plan handoff is awaiting review.
When an item is expanded, **Find in Plan** opens the same selected month in Plan, expands that item's owner and category, and focuses its row. Select the item there to use the existing editor, or use its row menu to remove it. Browser Back returns to the matrix and focuses the receiving account. The expanded item list resets when returning to Transfers. If the item was removed, focus returns to the matrix preview control.
